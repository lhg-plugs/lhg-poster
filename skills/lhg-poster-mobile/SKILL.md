# lhg-poster-mobile：手机端可读性自检

## 何时使用

- spec 写完、导出前，做"手机端可读性"终检时（`poster-audit` 的核心依据）。
- 收到别人做的海报，要快速判断"手机上能不能看"时。

**核心立场**：一切在电脑大屏上看着还行的设计，到 390px 宽的手机上都可能翻车。
**只认手机端效果**，不认设计稿效果。

## 输入输出

**输入**：`poster_spec.json` + 渲染出的成品图。

**输出**：可读性报告（机器审计结果 + 人工 3 秒测试结论 + 修改清单）。

## 分步方法论

### 第 1 步：机器审计（先过机检）

```text
python3 scripts/audit/poster_audit.py --target <目录> --format text
```

15 条规则中与可读性直接相关的：

| 规则 | 红线 | 说明 |
|---|---|---|
| PST-FONT-001 | 正文 < 40px（1080 宽） | 手机端看不清的硬红线，blocker |
| PST-CONTRAST-001 | 对比度 < 3:1 | 强光下看不清，blocker |
| PST-TEXT-001 | 文字溢出盒子 | 排版失控，blocker |
| PST-TEXT-002 | 占位符残留 | 发出去就是事故，blocker |
| PST-MARGIN-001 | 边距 < 4% 宽 | 圆角屏裁字，warning |
| PST-FONT-002 | 标题 < 正文×1.4 | 标题压不住，warning |

blocker 必须修完重跑，warning 逐条给处理意见（修或书面豁免）。

### 第 2 步：人工 3 秒测试（机检过后必做）

机器查不出审美问题，这一步不能省：

1. 把成品图缩到 **390px 宽**（手机 CSS 像素宽度），全屏看。
2. 掐表 3 秒，回答三个问题：
- 标题一秒内读懂了吗？（读不懂 → 标题字号/对比度/文案有问题）
- 遮住品牌名，还认得出是谁家的吗？（认不出 → 品牌露出太弱）
- CTA（扫码/电话）3 秒内找得到吗？（找不到 → 行动区被淹没）
3. 任一答案为"否" → 打回，按对应问题修（多半是版式问题，不是字号问题，
不要靠"调大字号"硬救）。

### 第 3 步：强光模拟（加分项）

把手机亮度调低一档看一遍：对比度勉强过线的（3:1~4.5:1），
低亮度下会直接看不清。户外场景多的海报（地推、门店），
对比度建议提到 4.5:1 以上。

### 第 4 步：错别字终查

海报发出去错一个字，品牌损伤不可逆。终查方法：

1. 把 spec 里所有 `text` 抽出来通读一遍（脱离版式读，错字更明显）。
2. 重点查：品牌名、时间、地点、电话/微信号（数字最容易错）。
3. 电话/微信号逐位核对——错一位就是别人的号。

### 第 5 步：输出报告

```text

机检：15 条规则，blocker 0，warning 1（PST-MARGIN-001：CTA 左边距 40px < 43px，已修）
人工 3 秒测试：通过（标题 1 秒读懂 / 品牌可识别 / CTA 可见）
错别字终查：通过（电话已逐位核对）
结论：可交付
```

warning 不修必须写一句话豁免理由，没有"下次再说"。

## 交付前检查表（打印版）

```text
□ 审计脚本零 blocker（python3 scripts/audit/poster_audit.py）
□ warning 逐条有处理意见（修 / 书面豁免）
□ 390px 宽 3 秒测试：标题懂 / 品牌认得出 / CTA 找得到
□ 低亮度看一遍（户外海报重点查）
□ 所有 text 脱离版式通读，无错别字
□ 品牌名写法与 brand.yml 一字不差
□ 电话/微信号逐位核对
□ 时间地点与需求清单一致
□ 占位符（{{}}/TODO/XXX/[待填]）零残留
□ 导出 PNG 宽度 = spec canvas 宽度（未缩放）
□ 放大 200% 文字边缘不发虚
```

11 项全勾才能发。少一项，就是给未来的自己埋雷。

## 质检话术（打回时用）

打回不是"不行"，要给出路。话术模板：

```text
这版在手机上 3 秒测试没过：[标题读不懂/品牌认不出/CTA 找不到]。
问题在[版式/对比度/字号]，建议[具体改法]，改完我再验一遍。
```

不要说"感觉不太对"——"感觉"是设计师最恨的词。
每次打回必须指出**具体哪条标准没过**（引用本 skill 的章节），
这是质检员的专业度。

## 常见翻车 Top 5

1. **电脑上好看，手机上糊**：没做 390px 缩放测试。
2. **强光下全瞎**：对比度卡着 3:1 的线，低亮度直接没。
3. **标题被装饰盖住**：AI 背景图太花，文字层没加罩。
4. **电话错一位**：没逐位核对，咨询打到别人那去了。
5. **占位符发出去了**：`{{时间}}` 印在海报上，全网社死。

## 反模式

- ❌ 只在电脑大屏上看效果就交付。
- ❌ 审计有 blocker 还说"差不多能用"。
- ❌ 3 秒测试没过，靠"调大字号"硬救（多半是版式问题）。
- ❌ warning 不写豁免理由直接放行。
- ❌ 电话/微信号不逐位核对。

## 自检与反馈

**质检门**（报告发出前自查）：

- [] 审计零 blocker（有 warning 必须有豁免理由）
- [] 390px 下 3 秒测试三个问题全"是"
- [] 电话/微信号已逐位核对
- [] 所有 text 已脱离版式通读一遍
- [] 结论是"可交付"或"打回"，没有"差不多"

**标准冒烟用例**：用插件 `fixtures/bad` 跑本节流程，
机检应有 blocker（PST-TEXT-001/002 等），结论为"打回"；
用 `fixtures/good` 跑，应零 blocker 且 3 秒测试可通过。

**一键反馈**：发现新的手机端翻车模式（如折叠屏异形），到本仓库提 issue，
标题格式 `[mobile] 一句话描述`，附上机型与翻车截图描述。
